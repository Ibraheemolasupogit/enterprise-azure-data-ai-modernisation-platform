# Data

This directory is reserved for synthetic data assets only.

- `raw/`: local raw synthetic data placeholders.
- `interim/`: local intermediate data placeholders.
- `processed/`: local processed data placeholders.
- `schemas/`: future data contracts and schemas.
- `contracts/`: machine-readable contracts for source feeds, identifiers, and events.
- `samples/legacy_estate/tiny/`: committed tiny synthetic fixture for review and tests.

See [docs/synthetic-data-strategy.md](../docs/synthetic-data-strategy.md) for the domain model and generation rules.
See [docs/legacy-estate.md](../docs/legacy-estate.md) for the Milestone 2 source estate.
