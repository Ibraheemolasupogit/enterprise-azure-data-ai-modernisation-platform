# Azure SQL

Milestone 2 adds SQL Server-style legacy OLTP source assets in [legacy_oltp](legacy_oltp). These scripts represent source-system technical debt for future assessment and migration; they are not Azure SQL deployment scripts.

Future milestones will add SQL modernisation assets here:

- Target selection assessment patterns.
- Database project or migration structure.
- Security baselines.
- Query performance and indexing automation.
- HA/DR and operational resilience scripts.

No Azure SQL resources are deployed in Milestone 2.
