# Azure SQL Operations Assets

These assets define operational patterns for the `legacy_tms` Azure SQL Managed Instance target.

- `security/`: Entra-first database roles, grants, classification, masking, and RLS examples.
- `agent_jobs/`: representative SQL Agent job definitions for Managed Instance.
- `kql/`: Log Analytics queries for operational investigation.

Milestone 6 does not execute these scripts against Azure.
