# Data Engineering

Milestone 2 adds a PostgreSQL-like secondary operational source schema in [secondary_sources/postgres_billing](secondary_sources/postgres_billing). It exists to create integration complexity for future ingestion, modelling, and data-quality work.

Future milestones will add ingestion, modelling, and data-quality code here:

- Source adapters.
- CDC processing.
- Streaming ingestion.
- Bronze, silver, and gold transformations.
- Quality rules and quarantine patterns.

Milestone 2 contains no executable data pipelines.
